# SNS 图片文字排版与可编辑模板

Store `/store/sns` 与 OS `/os/sns` 共用编辑器。图片文字与用于复制的投稿文相互独立。本文描述实现和验证方法，发布与实体设备验收证据单独记录。

## 输入与排版

1. 选择有权限的まぁ麻门店、照片、Logo 尺寸及黑/白 Logo 字色。
2. 直接在文字输入框输入，不需要选择预设文案；每次「文字を追加」创建空文字层，最多八层，每层最多180个字符。可选版式仅整理现有前两层，不增加或替换文案。
3. 各层独立调整字体、字重、字号、字距、行距、换行框、对齐、颜色、阴影。自动换行或缩小过长文字，以保留完整内容。
4. 「文字の実幅」指实际可见字形宽度。输入宽度或使用±10%同时缩放字号、字距和换行框，保留现有换行。「ほかの文字をこの幅に揃える」使用所有非空层可达到的共同实际宽度；达不到时提示且保留编辑内容。
5. 小于600px采用预览随页面滚动的上下布局，避免覆盖输入框。600–960px采用左控件、右预览，预览高度随窗口收缩。实际折叠屏键盘和触摸需另行设备验收。

## 多选与分组

- 「複数選択」显示勾选框，也支持桌面Shift/Ctrl/Cmd点选。点选已成组的成员会选择整组；内容和样式编辑应用于当前成员。
- 选中至少两个文字层后「グループ化」，分组关系保存到模板。可解除分组，不支持嵌套组。删除成员后清理只剩一个成员的分组。
- 拖动、方向键、XY数值和画布居中按整个选区移动，成员使用同一位移，保留间距。文字（包括空框）接近安全边界时共同限制位移。Shift+方向键加大步长。
- 分组居中和吸附按整组可见字形的联合边界计算；组内成员不作为自身的吸附目标。单层水平居中仍将各行设为居中对齐。
- 粉色参考线可吸附画布中线和其他文字的边缘/中心。屏幕6px内捕获、10px外释放；Alt暂时解除，方向键不吸附。只有真正到达对齐位置才显示参考线，选区和参考线不进入导出。

## 字体和颜色

- 保留三种系统字体类别，增加8种版本化自托管字体：Noto Sans JP、Noto Serif JP、Zen Maru Gothic、Shippori Mincho、Inter、Barlow Condensed、Bodoni Moda、IBM Plex Mono。
- 字体按使用的家族、字重和实际文字懒加载；含日文的拉丁字体同时加载自托管日文后备。完整字库及各家族OFL位于`public/fonts/sns/v1/`，来源与散列记录在`sources.json`。
- 加载完成后再测量、夹取、吸附和绘制；旧的异步结果不能覆盖新输入。导出和模板缩略图重新绘制已等待字体的精确快照。失败保留草稿并提供重试，不静默导出后备字体。旧系统字体在不同设备仍可能不同。
- 文字支持颜色选择器和3/6位HEX输入。收藏色规范化为`#RRGGBB`，每账号最多32种，跨设备读取；新增/删除使用数据库行锁更新，避免多端操作覆盖整份调色板。

## 可编辑模板和权限

- 仅保存图片时照片继续在端末处理。点击保存模板时，上传已校正方向、最长边≤2160px的无损PNG工作照片及小尺寸JPEG缩略图，保留照片、裁切、Logo、全部文字属性、分组、字体ID、格式和投稿文。
- 打开模板后可修改所有编辑内容。原作者或有权限的店铺管理角色可更新原模板；其他有该店权限的员工可打开并另存。另存使用新模板ID，原模板保持可用。
- 同时更新使用revision比较；发生冲突保留当前草稿，提示另存或重开。创建和原样更新重试幂等，避免丢失响应后重复保存。模板列表按时间分页，继续加载早期模板。
- 元数据存于既有`module_settings`的`store:<id>/sns_template:<uuid>`，私有资产登记为`sns_asset:<uuid>`；收藏存于`employee:<id>/sns_preferences`。无需新增数据库表或迁移。
- 所有读写重新验证有效登录、门店范围、active门店/品牌和exact品牌名`まぁ麻`/`maamaa`。OS另验`module.procedures`。跨门店ID不能扩大访问权限。
- 原图通过认证路由流式读取，`private,no-store`。未绑定模板的上传文件仅上传者可读；已绑定文件按门店模板访问范围读取。原图、签名Token和内部Blob路径不通过模板列表公开。
- 客户端直接上传私有Blob，绕开服务端请求体大小上限。短效Token仅签已登记的精确路径、类型和大小，禁止覆盖；上传完成须认证确认并校验文件头、大小、尺寸及完整图像解码，再标记ready。没有匿名完成回调或任意URL签名。
- 模板不自动删除共享资产；本版不提供模板删除。照片和新生成缩略图不可覆盖，另存可复用有权限的既有原图。

## 合成、保存与边界

- 先裁切照片，再绘制文字，最后绘制官方Logo。输出固定1080×1920 PNG/JPEG，沿用下载及分享通道，不自动投稿SNS。
- 可见文字左右/顶部保留32px，下边界y=1580，避开Logo区域。Canvas预览、命中、选择和导出共用字素/实际字形度量。
- HEIC/HEIF不支持。用户照片≤25MB、80MP、长短边比≤8；解码工作位图最长边≤2160。保存模板后的工作照片不重复缩放，重开保留裁切坐标。
- Store App仍通过`Foundr1Downloads.supportsImages()`使用既有PNG/JPEG下载桥；旧App提示升级。此Web功能不修改APK。真实Android下载目录、软件键盘、触摸和系统分享需实体设备验证。

## 验证

- `node --experimental-strip-types --test scripts/tests/sns-{composition,typography,text-alignment,text-resize,selection,fonts}.test.ts`
- 设置`SNS_LIBRARY_TEST_PGLITE_MODULE`为本机`@electric-sql/pglite`模块入口后运行`sns-library.test.ts`，用项目真实settings DDL验证SQL、权限、分页、冲突、上传及收藏。未设置时SQL测试明确跳过。
- 最终代码执行`npm run build -- --webpack`及`git diff --check`。
- 浏览器验证直接输入、八层、分组移动/居中、字体加载、收藏、模板保存/重开/更新/另存、PNG/JPEG和代表性响应尺寸。本地架空数据验证不能替代生产登录、云端Blob和真实手机验收；结果应明确区分。
