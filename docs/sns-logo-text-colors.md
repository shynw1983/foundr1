# SNS logo 文字颜色 — 实现与验收

分支基于生产 `918ec286db3440176da244b306392985670c4983`。不含未发布下载反馈热修复 `28a4202` 或 Android 候选改动；本次已获用户明确授权发布Web字色功能；不进行APK重构或版本递增。

## 素材与行为

`node scripts/create-sns-logo-colors.mjs` 从既有官方提取资产生成透明黑字/白字PNG。原红章到x130，右侧两行文字从x151开始；只改变x151及右侧已有文字像素的RGB，所有alpha、红章及内部白字、原字形/间距不变。原官方提取资产SHA仍为 `37e1c62ffc4b190e1c7121e36c1165580db0e05b2f8c264f1e18c291f3b86eeb`，没有AI重画。

编辑器新增“黒文字／白文字”手动选择，原黑字为初始值，无背景识别或自动切换。选择颜色不重置照片或构图。A `(345,1658,390,130)`、B `(403,1651,274,91)` 尺寸和位置不变。导出文件名含颜色，PNG/JPEG仍1080×1920。

认证素材API加 `color=black|white`，缺省black；非法值400。门店/品牌范围与OS权限继续先验证，资产保持private/no-store，原Tracing wildcard包含两资产。素材PNG源尺寸均390×130，B在合成时使用原有缩放。
